Homework 2: circuit satisfiability

Question. Before the modern polynomial encoding, how can ordinary commitments and gate-level Sigma protocols certify that a Boolean circuit has a satisfying assignment?

A Boolean circuit has wires carrying bits, with gates that compute XOR or AND. The language \(C_{\rm SAT}\) contains circuits with some input assignment yielding output 1. Assume perfectly binding, computationally hiding commitments to bits and Sigma protocols for proving that three committed values satisfy the XOR or AND relation.

This construction illustrates the same structural issue that PLONK solves more succinctly: each gate must be correct, and shared wires must have the same value everywhere. It is not itself the SNARG construction because the number of commitments and gate proofs grows with circuit size.

HW2 · Problem 4(a)

Construct a Sigma protocol for circuit satisfiability

Given \(N\) gates, run \(N\) parallel gate Sigma protocols, using the appropriate XOR or AND relation. Explain the prover's first message, the verifier's challenges, the prover's responses, and acceptance.

Construct the full protocol

The prover begins with a satisfying input assignment and computes all wire values. For each distinct logical wire \(w\), it creates one commitment \(c_w=\operatorname{Commit}(m_w;r_w)\), where \(m_w\) is its bit value and \(r_w\) is fresh commitment randomness. The same commitment is referenced by every gate using that wire.

For each gate \(j\), the public statement of the corresponding gate proof is the triple of commitments to its two inputs and output. The prover computes the gate Sigma protocol's first message \(a_j\) and sends all \(c_w\) and all \(a_j\) together.

The honest verifier samples independent challenges \(e_j\) for every gate, and sends them together. The prover computes all gate responses \(z_j\) using the committed wire values and openings, and sends them in one batch. It also opens the commitment to the final output wire, revealing the value 1.

The verifier checks the final output commitment opens to 1 and accepts every gate Sigma proof \((a_j,e_j,z_j)\) under its corresponding commitments.

A satisfying assignment makes every committed gate relation true and makes the final output 1. Thus perfect completeness of the gate protocols and honest commitment openings give completeness of the combined circuit proof. \(\square\)

HW2 · Problem 4(b)

Prove soundness from the gates

Show that if an unsatisfiable Boolean circuit were accepted with non-negligible probability, at least one gate Sigma protocol must have non-negligible soundness error.

Trace the contradiction to a particular gate

Perfect binding makes each committed wire value fixed. Because a single commitment is reused for every occurrence of a logical wire, the commitments define a global assignment of values to the circuit's wires. The output commitment is opened to 1.

But the circuit is unsatisfiable: no assignment can make every gate correct while the output is 1. Therefore at least one committed gate triple violates its prescribed XOR or AND relation. Acceptance of the full proof would require accepting the Sigma proof for that false gate statement.

If the overall false-acceptance probability were \(\varepsilon\), a union-bound argument over the \(N\) gate statements shows that some gate-level soundness failure must occur with probability at least \(\varepsilon/N\). For polynomial \(N\), non-negligible \(\varepsilon\) makes \(\varepsilon/N\) non-negligible.

Hence an accepted unsatisfiable circuit would yield a violation of at least one underlying gate protocol's soundness. The reduction works because shared wire commitments and the opened output force a concrete globally inconsistent assignment. \(\square\)

HW2 · Problem 4(c)

Describe a zero-knowledge simulator

Give the intended honest-verifier simulation strategy and explain which properties are needed to argue that simulated proof data resembles a real interaction.

Official solution outline and exact security caveat

The homework's intended outline is: create hiding commitments to convenient dummy wire values (such as 1 for every wire, so the output can be opened as 1); invoke the honest-verifier simulators of the gate Sigma protocols to make their transcripts; package these into a simulated circuit transcript. The commitments aim to hide whether their underlying bits match the actual satisfying assignment.

Crucial formal distinction: if every dummy wire is 1, an XOR gate has the invalid relation \(1\oplus1\ne1\). Ordinary HVZK only promises simulation of transcripts for true gate statements. It does not, by itself, guarantee that the gate simulator produces accepting transcripts for arbitrary false committed triples. Nor does hiding alone justify changing public statements inside already simulated proofs without a careful hybrid or equivocation argument.

Thus the provided course solution is an informal simulation sketch rather than a complete theorem from the stated gate Sigma protocol assumptions. To make it rigorous one needs suitable simulation properties for the particular gate-proof construction or another justified hybrid that handles the false dummy statements.

The exam-intended idea is to use hiding commitments and gate-transcript simulators; a fully rigorous ZK conclusion requires the extra simulator behavior just identified. Stating the missing hypothesis is more precise than pretending that hiding alone completes the proof. \(\square\)

Midterm: a polynomial commitment is a vector commitment

Exam objective. Apply interpolation to turn one primitive into another, then prove the new binding property from the original one.

2025 midterm · Problem 1(c) · Two marks

True or false: given a polynomial commitment for degree-at-most-\((d-1)\) polynomials over \(\mathbb F\), we can construct a vector commitment for vectors in \(\mathbb F^d\) with the same commitment and opening sizes.

Full one-paragraph exam solution

True, provided the field contains at least \(d\) distinct elements. For a vector \(\mathbf v=(v_1,\ldots,v_d)\), interpolate the unique polynomial \(f\) of degree at most \(d-1\) satisfying \(f(i)=v_i\) at distinct field points \(i=1,\ldots,d\). Commit to \(f\). To open vector position \(i\), open the polynomial commitment at point \(i\) and reveal \(v_i\).

Correct polynomial openings produce the true vector value. If a cheating prover could open the same vector commitment at position \(i\) to two different values, it would produce two valid polynomial openings at the same point with different outputs, contradicting evaluation binding.

The construction inherits position binding, and the commitment/opening objects are unchanged, so their sizes are inherited too. This proves the assertion. \(\square\)

Can every gate be correct while the circuit is wrong?

Exam objective. Identify the exact algebraic condition a false trace violates and explain why the other tests do not imply it.

Consider the lecture's three-gate circuit \((x_1x_2)(x_2+w_1)\), with public \(x_1=2,x_2=4\) and witness \(w_1=3\). A prover supplies the following table as its circuit trace:

GateLeftRightOutputOperation
0248\(\times\)
1437\(+\)
29763\(\times\)
Constructed exam-style problem

(a) Verify all three gate computations. (b) Determine whether the trace represents the original circuit. (c) Express the incorrect relation using \(f_{\rm trace}\) and \(\omega\). (d) Explain why a gate ZeroTest alone cannot reject this table.

Prove the answer step by step

(a) Every row is locally correct: \(2\cdot4=8\), \(4+3=7\), and \(9\cdot7=63\). Therefore the gate polynomial vanishes at every corresponding gate position.

(b) The actual circuit connects gate 0's output to gate 2's left input. These locations must encode the same logical wire. But the table claims gate 0 produced 8 while gate 2 used 9, so it does not describe any execution of the specified circuit with these wire connections.

(c) Under the lecture's trace indexing, gate 0's output is \(f_{\rm trace}(\omega^2)=8\) and gate 2's left input is \(f_{\rm trace}(\omega^6)=9\). The violated constraint is

\[\boxed{f_{\rm trace}(\omega^2)=f_{\rm trace}(\omega^6),\qquad 8\ne9.}\]

(d) The gate ZeroTest only enforces arithmetic within each triple. It accepts these three local triples, since all their gate residuals equal zero. The wiring IOP checks equal values where the same logical wire occurs in different triples, which is precisely where the contradiction appears.

This is a concrete counterexample to “all gates correct implies a correct circuit.” The correct implication needs both gate constraints and wire-copy consistency. \(\square\)

Construct a soundness proof from a verifier equation

Exam objective. Starting from a new polynomial-verification rule, decide exactly which theorem applies and close the entire soundness argument.

Let \(\mathbb F\) be a finite field of size \(p\). A prover claims that \(f(X)\), whose degree is at most 5, is zero at each point of \(\Omega=\{1,2,3\}\). It submits a candidate quotient \(q(X)\) of degree at most 5. The verifier picks uniform \(r\in\mathbb F\) and accepts if

\[f(r)=q(r)(r-1)(r-2)(r-3).\]
Constructed written-exam exercise

(a) Explain why the protocol has perfect completeness. (b) If the claimed vanishing property is false, give a concrete polynomial whose roots are exactly the potentially accepting challenges. (c) Prove that polynomial is nonzero. (d) Bound its degree and hence the verifier's false-acceptance probability. (e) Explain which step would fail if the prover could choose \(q\) after seeing \(r\).

Full proof with a final logical conclusion

(a) Completeness. If \(f(a)=0\) for all \(a\in\Omega\), the vanishing-polynomial theorem implies \(f(X)=q(X)(X-1)(X-2)(X-3)\) for some quotient \(q\). An honest prover submits it, so the verifier's equation holds at every challenge.

(b) The discrepancy polynomial. Define \(Z_\Omega(X)=(X-1)(X-2)(X-3)\) and \(h(X)=f(X)-q(X)Z_\Omega(X)\). The verifier accepts exactly when \(h(r)=0\).

(c) Nonzeroness. If the claim is false, then \(f(a)\ne0\) for at least one \(a\in\Omega\). At that \(a\), \(Z_\Omega(a)=0\), hence \(h(a)=f(a)\ne0\), independently of \(q\). Therefore \(h\) cannot be the zero polynomial. This direct argument also avoids presuming that a dishonest quotient exists.

(d) Degree and probability. Since \(\deg f\le5\), \(\deg q\le5\) and \(\deg Z_\Omega=3\), we have \(\deg h\le\max(5,5+3)=8\). By the root theorem, a nonzero degree-at-most-eight polynomial has at most eight field roots, so for uniform \(r\),

\[\boxed{\Pr[\text{false acceptance}]\le\min\left(1,\frac8p\right).}\]

(e) Timing. The probability bound assumes that a fixed polynomial \(h\) exists before \(r\) is sampled. If the prover can adapt \(q\) to \(r\), then the polynomial whose roots we count changes with the challenge, and the same one-variable root-count experiment no longer applies.

The false statement makes \(h\ne0\); the degree bound makes its root set small; the verifier errs only upon selecting one of those roots. These three established facts imply the displayed soundness bound. \(\square\)
