HW4 1a · An ideal oracle and its cryptographic implementation

Assume in the standard model, without a random oracle. Is the PLONK polynomial IOP still sound?

Show step-by-step solution

  1. A polynomial interactive oracle proof (Poly-IOP) gives the verifier an ideal interface to fixed polynomials with enforced degree bounds. Soundness means a false claim is accepted only with the stated small probability; it does not mean the prover's witness is hidden.

  2. Its algebraic tests choose random points after the relevant polynomials have been fixed. A false degree-bounded identity can hold at only a bounded number of field points. This root-counting fact does not depend on the prover's computing time.

  3. Thus the intended answer is true for the ideal Poly-IOP, including its required consistency checks. The hypothesis does not invalidate a field theorem. It can, however, invalidate the computational commitments used to implement those oracles. Soundness of the ideal object must be distinguished from security of a deployed SNARG.
