Part III · Graph Hamiltonicity

Two questions about the same hidden graph

The prover has fixed a relabeled graph \(B\) and the renaming \(\pi\) inside commitments. The verifier will choose one of two questions. The prover must be able to answer either, but it won't know which one is coming when it commits.

ProverSelects one random \(\pi\), computes \(B=\pi(G)\), and sends \(\mathrm{Commit}(\pi)\) plus commitments to every \(B_{ij}\).
VerifierSamples a single fair bit \(c\in\{0,1\}\). Only one branch is requested in any real execution.
ProverProvides the openings requested by the chosen \(c\), without altering the original commitments.

Nothing is open yet. Every entry is fixed by its commitment, but the verifier cannot read it.

The verifier can inspect only the values whose commitments the prover opens. All unopened values remain concealed.

Why two challenges?

If \(c=0\): isomorphism

For challenge \(c=0\), the prover reveals the permutation \(\pi\) and every graph entry. The verifier checks \(B=\pi(G)\): was this graph obtained by renaming the public graph correctly? This check does not require revealing a Hamiltonian cycle.

If \(c=1\): cycle

For challenge \(c=1\), the prover reveals only the committed edge values along a cycle in \(B\). The verifier checks that every claimed edge exists and the cycle visits each vertex once. It does not learn \(\pi\) or the remaining graph entries.

Notice the limitation of each question. The \(c=0\) question checks that \(B\) is the right graph, but not that it contains a cycle. The \(c=1\) question checks that \(B\) has a cycle, but not that it is a renamed copy of \(G\). Neither check alone proves everything.

Why is that good enough? On a false claim, a cheater must fix a graph before the challenge. We will prove that no single fixed graph can make both answers valid. The verifier catches the cheater with probability at least one half.

We'll now prove the two promises: an honest prover passes both challenges, and a cheater claiming a cycle in a graph without one can pass at most one of the two equally likely challenges.
