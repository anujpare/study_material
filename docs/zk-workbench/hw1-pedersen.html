Homework: why knowing a logarithm changes everything

Two commitment formulas can look almost the same and still have opposite security properties. Let's calculate what happens when the committer knows the discrete-logarithm relation between the public generators.

Pedersen commitments with a known generator relation

Let \(G\) be a group of prime order \(q\), generated by \(g\). Let \(h=g^t\) for some nonzero \(t\in\mathbb Z_q\). The Pedersen commitment to message \(m\), using random \(r\), is \(C=g^m h^r\).

\[C=g^m h^r=g^{m+tr}\]

Since \(h=g^t\), we may write \(C=g^{m+tr}\). We call the known generator relation \(t\) to keep it separate from the secret \(x\) in Schnorr's protocol. The crucial question is whether someone who knows \(t\) can change \(m\) while keeping the exponent \(m+tr\) unchanged.

Suppose \(C\) was made using \(m,r\), but we want to open it as a different \(m'\). The verifier will accept if \(m'+tr'\equiv m+tr\pmod q\). We can solve that equation for the required new randomness \(r'\).

\[r'=r+(m-m')t^{-1}\pmod q\]

Because \(q\) is prime and \(t\ne0\), the inverse \(t^{-1}\) exists. The formula below chooses exactly the \(r'\) that keeps the exponent unchanged. Substituting gives \(g^{m'}h^{r'}=g^m h^r=C\), so the alternative opening verifies.

Show hiding survives even though binding fails

Hiding still works. For any fixed \(m\), the exponent \(m+tr\) runs uniformly through \(\mathbb Z_q\) when \(r\) is uniform, because multiplying by nonzero \(t\) and then adding \(m\) merely permutes the field elements. Hence \(C=g^{m+tr}\) is uniform in the group regardless of \(m\). So Pedersen remains perfectly hiding even though knowing \(t\) destroys binding.

HW1 2(d) · Why the ElGamal-style pair behaves differently

Now consider a different commitment that sends two group elements instead of one:

\[C=(g^r,\ g^m h^r)\]

The first component is \(g^r\); the second is \(g^m h^r\). Again suppose \(h=g^t\) and \(t\) is known. The extra first component changes what the committer can get away with.

Prove binding

If two openings make the same pair, the first components give \(g^r=g^{r'}\), so \(r=r'\pmod q\). With the randomness fixed, equality of the second components gives \(g^m h^r=g^{m'}h^r\), hence \(g^m=g^{m'}\). As \(g\) has order \(q\), this forces \(m=m'\pmod q\). Thus two different messages can never open the same pair: it is perfectly binding.

Disprove statistical hiding

Now check hiding. Since (t) is known, an observer can remove the blinding factor from the second component by dividing by the first component raised to (t):

\[\frac{g^m h^r}{(g^r)^t}=\frac{g^m g^{tr}}{g^{tr}}=g^m.\]

The result is \(g^m\). An unlimited observer can compute its discrete logarithm to recover \(m\), so the scheme is not statistically hiding. For a small message space, even an efficient observer might enumerate the possibilities.

We have now seen both security properties in algebra, not just in words. The graph protocol needs a commitment that hides its entries and keeps them fixed after the verifier asks its challenge.
