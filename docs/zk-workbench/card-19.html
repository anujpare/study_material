Part VII · Schnorr identification

Two accepted answers reveal Schnorr's secret

The simulator established Schnorr's honest-verifier zero knowledge, but privacy is only one required property. We still need to show that accepting answers demonstrate knowledge of a witness. Special soundness gives a concrete test: can two accepted transcripts with the same first message and different challenges be combined to recover the secret? If one Schnorr first message \(u\) can be answered correctly for two different challenges, the two verification equations contain enough information to recover secret \(x\). Let's solve them, step by step.

Homework 2 · Problem 3(c)

The task

Homework assumption: the prover \(P^\ast\) can answer every challenge successfully. Build an extractor that recovers \(x\). If it chooses two challenges independently, show that extraction succeeds with probability \(1-1/q\).

Collect two accepting transcripts with the same \(u\)

The extractor runs the prover until it sends \(u\), then saves the prover's internal state. It sends challenge \(c\) and receives \(z\). It rewinds to the saved state, so \(u\) stays the same, sends a fresh challenge \(c'\), and receives \(z'\). Both responses pass the verifier.

\[\begin{aligned}g^z&=u\,h^c\\g^{z'}&=u\,h^{c'}.\end{aligned}\]

The mark in \(c'\) means “a second value.” The two equations share \(u\) because the prover was rewound to the same first-message state.

Cancel the shared commitment, then solve

Divide the accepting equation for \((u,c,z)\) by the one for \((u,c',z')\). The shared \(u\) cancels, leaving \(g^{z-z'}=h^{c-c'}\). Now use the public relation \(h=g^x\):

\[\begin{aligned}g^{z-z'}&=h^{c-c'}\\&=g^{x(c-c')}\\\Longrightarrow\quad z-z'&=x(c-c')\pmod q.\end{aligned}\]

Since \(g\) has order \(q\), equal powers of \(g\) have exponents equal modulo \(q\). So we get an ordinary linear equation for \(x\), but in modular arithmetic.

If \(c\ne c'\), the number \(c-c'\) is nonzero modulo prime \(q\) and has an inverse. Multiply by that inverse to isolate \(x\):

\[\boxed{x=(z-z')(c-c')^{-1}\pmod q}\]

The inverse \((c-c')^{-1}\) is how division works modulo \(q\). If the challenges are equal, the inverse doesn't exist and this pair of responses gives no extraction.

Try the extractor numerically

Find the secret from two responses

Try the small example: \(p=23,q=11,g=2,h=8\). The first response uses \(r=4,c=2,z=10\). Choose a second challenge \(c'\) and calculate the recovered exponent.

Why the probability is \(1-1/q\)

With our always-successful prover, the only failure is \(c'=c\). The second challenge is uniform among \(q\) possibilities, and exactly one equals \(c\). So the failure chance is \(1/q\), and the extraction chance is \(1-1/q\).

We have recovered a real witness from two accepted transcripts. Next we'll use the same commitment/challenge/response pattern to prove facts about entire circuits.
