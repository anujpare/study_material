Part VII · Schnorr identification

Extract Schnorr's secret from two accepting challenges

A prover that can answer two different challenges for the same commitment cannot merely be lucky. We will show that the two accepted equations contain enough information to solve for the secret exponent \(x\) using ordinary algebra modulo the group's prime order.

Homework 2 · Problem 3(c)

The task

Assume a prover \(P^\ast\) can successfully answer every verifier challenge in Schnorr's identification protocol. Construct an extractor that rewinds the prover and outputs the discrete logarithm \(x\). If the two challenges are sampled independently from \(\mathbb Z_q\), prove success probability \(1-1/q\).

Collect two accepting transcripts with the same \(u\)

The extractor runs the prover until it sends \(u\), saves the prover's internal state, and challenges it with \(c\), receiving \(z\). It rewinds the prover to that exact saved state—so the first message is still \(u\)—then challenges it with a fresh \(c'\), receiving \(z'\). The two verifier checks imply:

\[\begin{aligned}g^z&=u\,h^c\\g^{z'}&=u\,h^{c'}.\end{aligned}\]

A prime mark, as in \(c'\), means a second challenge, not a derivative. The same commitment \(u\) appears in both equalities because the prover was rewound to the same state.

Cancel the shared commitment, then solve

Divide the first group equation by the second. The factor \(u\) cancels, leaving \(g^{z-z'}=h^{c-c'}\). Substitute \(h=g^x\), then use that \(g\) has order \(q\) to compare exponents modulo \(q\):

\[\begin{aligned}g^{z-z'}&=h^{c-c'}\\&=g^{x(c-c')}\\\Longrightarrow\quad z-z'&=x(c-c')\pmod q.\end{aligned}\]

Exponents of a generator of order \(q\) are equal as group elements exactly when their difference is divisible by \(q\). Thus the final equality is a congruence modulo \(q\).

If \(c\ne c'\), the difference \(c-c'\) is nonzero modulo the prime \(q\), so it has a multiplicative inverse \((c-c')^{-1}\). Multiply both sides by that inverse to recover:

\[\boxed{x=(z-z')(c-c')^{-1}\pmod q}\]

This is modular division: multiply by the inverse of \(c-c'\). It is not an ordinary real-number fraction, and it is undefined if \(c=c'\pmod q\).

Try the extractor numerically

Find the secret from two responses

Use \(p=23,q=11,g=2,h=8\). For the first response, fix \(r=4\), \(c=2\), \(z=10\). Pick a second challenge \(c'\). The toy prover can answer all challenges for that same \(r\).

Why the probability is \(1-1/q\)

The only failure in this exercise's assumed always-answerable prover is choosing equal challenges, \(c'=c\). Since the second challenge is uniform among \(q\) possible values and only one equals \(c\), that event has probability \(1/q\). All other \(q-1\) choices let the extractor calculate \(x\). Hence \(\Pr[\text{extract }x]=1-1/q\). If the extractor deliberately chose two distinct challenges, this particular collision failure would disappear; the exercise explicitly considers independent sampling.

Schnorr establishes how to prove knowledge of a single exponent. The next construction combines many small proofs to verify that an entire Boolean circuit has a satisfying input, while keeping its intermediate values committed.
