Part I · Interactive proofs

What changes when the verifier can challenge the prover?

An ordinary proof is one message: the prover submits a witness and the verifier checks it. In an interactive proof, the prover and verifier exchange messages. Crucially, the verifier can make a random choice after the prover has committed to an initial answer.

The order of the messages creates the security

Prover PPrepares and sends a first message \(u\), before knowing the verifier's question.
Verifier VSamples a challenge \(c\) and sends it to the prover. In our simple example, \(c\) is either 0 or 1.
Prover PReturns a response \(z\). The verifier checks whether \((u,c,z)\) is consistent with a true statement.

The prover cannot choose the verifier's challenge. Nor may it revise the already-sent first message after learning the challenge. This is precisely the constraint that makes a random question useful.

Toy challenge game

Make one preparation before the verifier draws its challenge

Assume a cheating prover can prepare a valid answer for only one of two checks. This illustrates the timing rule; it is not itself a zero-knowledge protocol.

Which challenge will the cheater prepare to answer?

First choose a preparation. The challenge comes only afterward.

If the verifier independently chooses 0 or 1 with equal probability, the cheater succeeds with probability \(1/2\), because exactly one of the two equally likely challenges is answerable. Repeating a suitable protocol can reduce this chance, provided each round is properly constructed.

How to understand the formal definition

The notation \(\langle P,V\rangle(x)\) describes the complete interaction between a prover \(P\) and a verifier \(V\) on public statement \(x\). The final result is 1 if \(V\) accepts and 0 otherwise. The verifier is an efficient algorithm, meaning it must complete its work in polynomial time; the prover in the standard interactive-proof definition may have unlimited computational power.

We still need to specify what the verifier guarantees for true versus false statements. That gives the two fundamental properties on the next card.

What did the interaction accomplish? It made the prover respond to a question it could not anticipate when preparing its first message. Next we turn that observation into two precise probability guarantees.
