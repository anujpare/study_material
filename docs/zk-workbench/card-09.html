Part III · Graph Hamiltonicity

Prove completeness and soundness of the Hamiltonicity protocol

We want two precise results. If \(G\) really has a Hamiltonian cycle, an honest prover should always be accepted. If it has no Hamiltonian cycle, no cheating prover should succeed with probability more than \(1/2\).

Proof 1 · Perfect completeness

Assume \(G\) has a Hamiltonian cycle \(w\) and the prover knows it. The prover chooses \(\pi\) and commits to the genuine relabeled graph \(B=\pi(G)\).

Case \(c=0\): Opening \(\pi\) and every \(B_{ij}\) lets the verifier compare all entries with the public graph. They agree by the way \(B\) was constructed, so the verifier accepts.

Case \(c=1\): By the relabeling argument on the previous card, applying \(\pi\) to \(w\) produces a Hamiltonian cycle of \(B\). Each edge on that cycle is genuinely present and can be opened, so the verifier accepts.

Those are the only two possible challenges. Therefore the honest prover succeeds for either challenge, and \(\Pr[\mathrm{accept}\mid G\text{ has a Hamiltonian cycle}]=1\). This is perfect completeness.

Soundness starts with the assumption that the claim is false

Now assume \(G\) has no Hamiltonian cycle. The cheating prover still has to send all its commitments before the verifier chooses \(c\). Because the commitment scheme is perfectly binding, the prover cannot alter the committed graph after learning the challenge.

Call the already-committed graph \(B\), whether or not it was constructed honestly. There are only two possibilities:

Case A

If \(B\) really is isomorphic to \(G\), then \(B\) has no Hamiltonian cycle because isomorphisms preserve cycles. Thus challenge \(c=1\) must fail, although \(c=0\) might pass.

Case B

If \(B\) is not isomorphic to \(G\), then challenge \(c=0\) must fail, although \(c=1\) might pass if the cheating prover selected a different graph containing a cycle.

Proof 2 · Soundness error at most \(1/2\)

In either case, at least one of the two challenges necessarily fails. The verifier chooses its challenge uniformly, which means each of 0 and 1 has probability \(1/2\). The prover can therefore succeed with probability at most \(1/2\):

\[\Pr[\mathrm{accept}\mid G\notin L]\ \leq\ \tfrac12\]

The point is not that a typical cheater gets caught half the time. We have shown that every cheating strategy has at least one unavoidable failing challenge, because a graph with a cycle cannot simultaneously be an isomorphic copy of a graph with no cycle.

Hiding did not establish soundness here. Binding was the essential assumption because the committed graph had to remain fixed. Hiding enters in the next, harder claim: zero knowledge.

How can a simulator prepare a transcript that looks like either honest response if it does not know any Hamiltonian cycle of \(G\)? The answer uses a guess about the verifier's challenge and carefully controlled rewinding.
