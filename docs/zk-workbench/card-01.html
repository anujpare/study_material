Part I · What counts as a proof?

How do we verify a claimed Hamiltonian cycle?

Consider a graph \(G\) with five vertices. Someone claims that \(G\) contains a Hamiltonian cycle. We want to understand what evidence would establish that claim, and what the verifier actually needs to check.

Define the graph and the claim

Write \(G=(V,E)\). The set \(V\) contains the vertices, and \(E\) contains the edges. In this example, \(V=\{1,2,3,4,5\}\). An undirected edge \(\{u,v\}\in E\) means that vertices \(u\) and \(v\) are adjacent. The graph is undirected, so \(\{u,v\}\) and \(\{v,u\}\) refer to the same edge.

A Hamiltonian cycle is a sequence \(v_1,v_2,\ldots,v_n,v_1\) in which \(v_1,\ldots,v_n\) are all distinct, cover every vertex of the graph, and every consecutive pair—including \(\{v_n,v_1\}\)—belongs to \(E\). We repeat \(v_1\) at the end only to indicate that the sequence forms a cycle.

The claim is that such a sequence exists. The following graph is our public instance; we will inspect two proposed vertex sequences.

Gray segments represent edges in \(E\). For the selected candidate, green segments correspond to existing edges; a dashed red segment indicates a consecutive vertex pair that is not an edge of \(G\).

Verify a proposed witness

Which candidate satisfies the definition?

The graph \(G\) stays fixed. Only the candidate vertex sequence changes.

Select a candidate. The verifier will check every consecutive vertex pair and whether all vertices are visited exactly once.

Candidate A is a valid Hamiltonian cycle: the five vertices occur exactly once before returning to 1, and every required edge belongs to \(E\). Candidate B is invalid because \(\{3,5\}\notin E\). Rejecting Candidate B tells us only that this candidate fails; it doesn't imply that no Hamiltonian cycle exists. A single valid witness establishes a YES instance, while one invalid witness does not establish a NO instance.

Now identify the statement, witness, and verifier

The statement \(x\) is the public graph \(G\) together with the claim that it has a Hamiltonian cycle. The witness \(w\) is a proposed sequence of vertices. A deterministic checking algorithm \(M\) examines \(x\) and \(w\), checks the distinct-vertex and edge conditions above, and returns 1 only if all conditions hold.

\[M(x,w)=1\]

The value 1 means that this witness is accepted; 0 means that this witness is rejected. One rejected witness does not prove that the statement is false.

The verifier doesn't need to know how the prover found the cycle. It checks the witness against a public mathematical definition. This distinction between finding a witness and verifying a supplied witness is the starting point for the complexity class NP.

For this five-vertex graph, both tasks are manageable. For a large graph, however, finding a Hamiltonian cycle can require much more work than checking one that has already been supplied. The next lesson makes that distinction precise.
