Optional prerequisite for HW3 4 · Homework 1 · Problem 4(a–c)

How can one short commitment fix an entire vector of values?

The graph-Hamiltonicity protocol commits separately to matrix entries, while the later PCP construction must commit to an entire long proof string and then open only a few requested positions. Homework 1 asks you to construct three position-binding vector commitments with different trade-offs.

Define the property before designing the scheme

Let \(\boldsymbol{m}=(m_1,\ldots,m_n)\) be an ordered vector of messages, where position \(i\) contains \(m_i\). A vector commitment publishes \(c=\mathrm{Commit}(\boldsymbol{m})\). An opening \(\pi_i\) should convince the verifier that the message at position \(i\) was \(m_i\). Position binding means that no efficient attacker can open one fixed commitment \(c\) at the same index \(i\) to two different messages \(m_i\ne m_i'\).

\[\mathrm{Verify}(c,i,m_i,\pi_i)=1\]

The verifier checks an index \(i\), claimed message \(m_i\) and position-opening proof \(\pi_i\). This homework explicitly does not require hiding.

Homework 1 · Problem 4(a)

Large commitment; essentially free opening

Construct a vector commitment of length \(n\lambda\) bits with a constant-size opening, where \(H\) is a random-oracle hash outputting \(\lambda\) bits.

Construction and proof of position binding

Publish the whole vector of message hashes \(c=(H(m_1),\ldots,H(m_n))\). To open position \(i\), reveal \(m_i\) and no additional proof: the verifier checks \(H(m_i)=c_i\). The commitment has \(n\) hashes of \(\lambda\) bits each; the authentication proof beyond the opened message is empty, so it costs \(O(1)\) bits. If one index could open to distinct \(m_i\) and \(m_i'\), then \(H(m_i)=H(m_i')\), a collision. Finding such a collision requires exponentially many random-oracle queries for constant success probability.

Homework 1 · Problem 4(b)

Tiny commitment; reveal the entire vector

Construction and proof of position binding

Publish one hash \(c=H(\operatorname{encode}(m_1,\ldots,m_n))\), using an unambiguous encoding that records positions and lengths. To open index \(i\), reveal the entire vector. The verifier checks its \(i\)th component and recomputes \(c\). The commitment has \(\lambda\) bits; the proof reveals \(O(n|m|)\) bits for equal-size messages of \(|m|\) bits. Distinct valid openings at one index imply different encodings with the same hash, which is a collision.

Problem 4(c): find the middle ground with a Merkle tree

Hash each message to a leaf \(c_i=H(\mathrm{leaf}\Vert m_i)\). Combine adjacent child hashes using \(H(\mathrm{node}\Vert\mathrm{left}\Vert\mathrm{right})\) until only one \(\lambda\)-bit root \(c\) remains. Domain labels leaf and node make the input encodings unambiguous. The root fixes the entire vector, but opening one position needs only the sibling hash at each tree level.

For position 4, the opening contains the hashes of its siblings at each level: c₃, c₁₂ and c₅₈.

Prove the size bound and position binding

For \(n=8\), there are three binary levels, so one opening uses exactly three sibling hashes. For general \(n\), the number of levels is \(O(\log n)\), and each sibling hash has \(\lambda\) bits. Therefore the root is \(\lambda\) bits and a position proof has size \(O(\lambda\log n)\).

Suppose two different messages \(m\ne m'\) at the same index both verify under the same root. Starting at the leaf, the two hashes are different unless \(H\) already has a collision. Follow both authentication paths upward. If they end at the same root, there must be a first node where two different child-input encodings produce the same parent hash. That is another hash collision. Either way, successful double opening would break the random-oracle collision-resistance assumption; thus the scheme is position binding against efficient attackers.

This is the exact primitive used in Homework 3 Problem 4: a prover first commits to a long PCP proof using one short root, then opens only the positions selected by the verifier. The root must be fixed before those positions are chosen.
