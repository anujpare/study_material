Part VII · Schnorr identification

Simulate Schnorr backwards, without knowing the secret

An honest Schnorr prover first selects \(r\), then receives \(c\), and then calculates \(z=r+cx\). The simulator cannot do this because it does not know \(x\). Instead, it starts by selecting the public values \(c\) and \(z\), then algebraically constructs a compatible \(u\).

Derive the simulator's formula from the verifier's equation

The verifier accepts precisely when \(g^z=u h^c\). We want to choose \(u\) that makes this identity hold. Multiply both sides by \(h^{-c}\), the multiplicative inverse of \(h^c\), and obtain:

\[g^z=u\,h^c\quad\Longleftrightarrow\quad u=g^z\,h^{-c}\]

The negative exponent means a group inverse, not subtraction of integers. It is computed in the same group as \(h\). No value of the secret exponent \(x\) appears in this construction.

Simulator \(\mathrm{Sim}(h)\) · public input only

Choose \(c\) uniformly in \(\mathbb Z_q\). Independently choose \(z\) uniformly in \(\mathbb Z_q\). Compute \(u=g^z h^{-c}\). Output \((u,c,z)\). The verification equation is automatically satisfied because \(u h^c=(g^z h^{-c})h^c=g^z\).

Construct a transcript without \(x\)

The simulator never asks for the secret exponent

In this small example \(p=23\), \(q=11\), \(g=2\), and only the public value \(h=8\) is used to construct each transcript.

Generate \(c,z\), compute \(u\), and check the verifier's equation.

A valid-looking answer is not enough: prove identical distribution

In a real honest execution, \(c\) is sampled uniformly, independently of the prover's random \(r\). For any fixed \(c\), the map \(r\mapsto z=r+cx\pmod q\) adds the fixed quantity \(cx\) modulo \(q\), which permutes the possible values of \(r\). Since \(r\) is uniform, \(z\) is also uniform in \(\mathbb Z_q\).

Moreover, the real commitment is already determined by \(c,z,h\):

\[\begin{aligned}u&=g^r\\&=g^{z-cx}\\&=g^z(g^x)^{-c}\\&=g^zh^{-c}.\end{aligned}\]

We substitute \(r=z-cx\pmod q\), use exponent laws, and then use \(h=g^x\). This is the same deterministic formula as in the simulator.

Distribution comparison

In both experiments, \(c\) is uniform; conditional on \(c\), \(z\) is uniform; and \(u\) is the same function \(g^z h^{-c}\) of the pair \((c,z)\). Therefore the complete triples \((u,c,z)\) have exactly the same distribution. We have proved honest-verifier zero knowledge, not merely that the verifier accepts.

State what you have shown

“Show that Schnorr is honest-verifier zero knowledge; simulate the transcript by choosing \(z,c\) first and then \(u\).”

What must the proof contain?

Both pieces above are necessary: (1) algebraically show that \(u=g^z h^{-c}\) yields an accepting transcript; (2) prove that uniform \(r\) induces uniform \(z=r+cx\pmod q\) for every honest challenge \(c\). Only together do they establish the same distribution without the witness \(x\).

We have now proved completeness and honest-verifier zero knowledge. The third Sigma property is special soundness: from two accepting responses to one commitment, we must explicitly recover the secret \(x\).
