Part VII · Schnorr identification

Can we simulate Schnorr without knowing the secret?

Completeness showed that an honest Schnorr prover always satisfies the verification equation. That does not tell us whether its transcript reveals the secret exponent. To establish honest-verifier zero knowledge, we need a simulator producing the same transcript distribution without knowing that exponent. An honest Schnorr prover calculates \(z=r+cx\), which uses secret \(x\). A simulator does not know \(x\). So we can't imitate the honest steps in the usual order. Instead, let's start with the verifier's equation and work backwards.

Derive the simulator's formula from the verifier's equation

The verifier accepts when \(g^z=u h^c\). Suppose we first choose \(c\) and \(z\). Can we solve this equation for \(u\)? Multiply by the inverse \(h^{-c}\) to get

\[g^z=u\,h^c\quad\Longleftrightarrow\quad u=g^z\,h^{-c}\]

The negative exponent means group inversion. We know \(h\) publicly, so we can calculate \(h^{-c}\) without knowing the secret \(x\).

Simulator \(\mathrm{Sim}(h)\) · public input only

Here is the simulator: pick \(c,z\) independently and uniformly from \(\mathbb Z_q\), calculate \(u=g^z h^{-c}\), and output \((u,c,z)\). The verifier accepts because \(u h^c=g^z h^{-c}h^c=g^z\).

Construct a transcript without \(x\)

The simulator never asks for the secret exponent

Try the arithmetic with the small group modulo 23, where (g=2,q=11,h=8). The simulator uses only this public information.

Generate \(c,z\), compute \(u\), and check the verifier's equation.

A valid-looking answer is not enough: prove identical distribution

But a passing transcript isn't enough. It must have the same distribution as a real one. In the real protocol \(c\) is uniform, independent of \(r\). For any fixed \(c\), the value \(z=r+cx\pmod q\) is also uniform, because adding a fixed number merely rearranges all the possible values of \(r\).

What about (u)? Once we know (c,z,h), the verifier's equation already determines it:

\[\begin{aligned}u&=g^r\\&=g^{z-cx}\\&=g^z(g^x)^{-c}\\&=g^zh^{-c}.\end{aligned}\]

Substituting \(r=z-cx\) into \(u=g^r\) gives \(u=g^{z-cx}=g^z(g^x)^{-c}=g^z h^{-c}\). That's exactly how the simulator constructs \(u\).

Distribution comparison

So both experiments choose the pair \((c,z)\) uniformly, and in both the value of \(u\) is the same function \(g^z h^{-c}\). The entire transcript \((u,c,z)\) therefore has exactly the same distribution. That's honest-verifier zero knowledge, not merely a successful verifier check.

Homework 2 · Problem 3(b)

State what you have shown

“Show that Schnorr is honest-verifier zero knowledge; simulate the transcript by choosing \(z,c\) first and then \(u\).”

What must the proof contain?

A complete answer needs both facts: the simulated triple satisfies \(g^z=u h^c\), and its distribution matches the real one. The first gives acceptance; the second gives privacy.

We've now proved completeness and honest-verifier zero knowledge for Schnorr. To prove its special soundness, we'll see what happens if one fixed (u) can answer two different challenges.
