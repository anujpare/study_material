Part VI · Sigma protocols

One simple rule explains Sigma-protocol soundness

The Hamiltonicity extractor succeeded because two valid responses to different challenges, sharing one first message, determine a witness. We would like to recognize and prove this property without rebuilding the argument separately for every protocol. A Sigma protocol isolates the three-message structure and its precise extraction requirement. Hamiltonian-cycle proofs use graphs, and Schnorr will use exponents. Yet the same thing makes both work: after fixing a first message, the prover must answer a surprise challenge. A Sigma protocol captures that shared structure.

P → VCommitment \(u\), fixed before the verifier asks its question.
V → PChallenge \(c\), chosen uniformly from a finite set \(\mathcal C\).
P → VResponse \(z\). The verifier outputs \(\mathrm{verif}(x,u,c,z)\in\{0,1\}\).

Three properties in the definition

1 · Perfect completeness

Perfect completeness: when the claim is true and the prover follows the protocol, verification always accepts.

2 · Honest-verifier zero knowledge

Honest-verifier zero knowledge: for a true statement \(x\) and an honestly chosen challenge \(c\), an efficient simulator can create a convincing transcript \((u,c,z)\) without the witness. This alone says nothing about arbitrary malicious verifiers.

3 · Special soundness

Special soundness: if the same \(u\) has accepted responses to two different challenges \(c\ne c'\), an efficient extractor can recover a witness \(w\) with \(M(x,w)=1\).

Proof of the Sigma-protocol soundness theorem

Claim: soundness error is at most \(1/|\mathcal C|\)

Suppose the claim is false, \(x\notin L\). Fix any first message \(u\) sent by a cheating prover. There is no valid witness.

Imagine the prover could answer two distinct challenges \(c,c'\) correctly without changing \(u\). Special soundness would let us extract a valid witness from those accepted transcripts.

But a witness for a false statement cannot exist. So our assumption was impossible. For this fixed first message, at most one challenge can have an accepting response.

The verifier chooses \(c\) uniformly from a set \(\mathcal C\), after \(u\) has been fixed. At most one choice works. Therefore

\[\Pr[\mathrm{accept}\mid x\notin L]\leq\frac{1}{|\mathcal C|}\]

The notation \(|\mathcal C|\) means the number of possible challenges. The result holds for any cheating prover, including one that uses randomness before sending \(u\).

This is why Sigma protocols are so useful. When we can prove special soundness, a simple counting argument gives a soundness bound. Now we'll see the same reasoning expressed with exponents in Schnorr's protocol.
