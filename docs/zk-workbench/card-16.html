Part VI · Sigma protocols

One pair of accepting transcripts gives a general soundness theorem

The graph protocol and Schnorr identification appear different, but the same structure underlies both: commitment, challenge, response. Sigma protocols formalize the structural properties that make this pattern useful.

P → VCommitment \(u\), fixed before the verifier asks its question.
V → PChallenge \(c\), chosen uniformly from a finite set \(\mathcal C\).
P → VResponse \(z\). The verifier outputs \(\mathrm{verif}(x,u,c,z)\in\{0,1\}\).

Three properties in the definition

1 · Perfect completeness

For a true statement and honest prover, the verifier accepts every honest execution, with probability 1.

2 · Honest-verifier zero knowledge

Given a true public statement \(x\) and a desired challenge \(c\), an efficient simulator produces a transcript \((u,c,z)\) indistinguishable from an honest verifier's transcript conditioned on that challenge. This does not automatically promise security against an arbitrarily malicious verifier.

3 · Special soundness

There is an efficient extractor which, given two accepting transcripts \((u,c,z)\) and \((u,c',z')\) with the same \(u\) but distinct challenges \(c\ne c'\), outputs a valid witness \(w\) with \(M(x,w)=1\).

Proof of the Sigma-protocol soundness theorem

Claim: soundness error is at most \(1/|\mathcal C|\)

Step 1. Fix a false statement \(x\notin L\) and an arbitrary first commitment \(u\) sent by any cheating prover. Since \(x\) is false, no valid witness \(w\) exists.

Step 2. Suppose two distinct challenges \(c\ne c'\) could both lead to accepting responses for that same \(u\). Special soundness would let us run the extractor on the two accepting transcripts and obtain \(w\) with \(M(x,w)=1\).

Step 3. That contradicts \(x\notin L\). Therefore, for each fixed \(u\), at most one challenge in the challenge set can lead to acceptance.

Step 4. The honest verifier chooses uniformly among \(|\mathcal C|\) challenges after \(u\) is fixed. At most one can succeed, hence:

\[\Pr[\mathrm{accept}\mid x\notin L]\leq\frac{1}{|\mathcal C|}\]

The notation \(|\mathcal C|\) is the number of possible challenges. The bound applies to any cheating prover, including one that randomizes its first message or response.
