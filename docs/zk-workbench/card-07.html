Part III · Graph Hamiltonicity

Why does the prover randomly permute the vertices?

In the Hamiltonicity proof, the prover knows a Hamiltonian cycle of the public graph \(G\). Revealing that cycle with its original vertex labels would reveal the witness. We therefore need to preserve the mathematical claim while concealing the correspondence between the proof's vertex labels and those of \(G\).

Relabeling a graph without changing its edges

Write \(G=(V,E)\), where \(V=\{1,2,3,4,5\}\) is the vertex set and \(E\) is the set of undirected edges. A permutation \(\pi:V\to V\) is a bijection: every vertex receives a distinct new label, and every old label can be recovered using the inverse permutation \(\pi^{-1}\).

Suppose the prover knows the Hamiltonian cycle \(1\to2\to3\to4\to5\to1\). Here is one possible permutation:

\[\pi(1)=2,\quad\pi(2)=4,\quad\pi(3)=1,\quad\pi(4)=5,\quad\pi(5)=3\]

The demonstration fixes this permutation so you can inspect its effect. The honest prover chooses a fresh random permutation in each protocol execution.

Construct a new graph \(B=\pi(G)\) with the same adjacency relation under the new labels: for every edge \(\{u,v\}\in E\), the relabeled graph contains \(\{\pi(u),\pi(v)\}\), and no additional edges are introduced. This is a graph isomorphism. An edge remains an edge; only its endpoints' labels change.

Follow one edge through the permutation. The original edge \(\{1,2\}\) becomes \(\{\pi(1),\pi(2)\}=\{2,4\}\). Applying \(\pi\) to every vertex of the known cycle gives \(2\to4\to1\to5\to3\to2\). The sequence uses the same graph structure, expressed in new vertex labels.

Why is the relabeled cycle still Hamiltonian?

Reveal the permutation. Every green edge in the relabeled graph must correspond to an edge in the original graph.

The permutation acts on both endpoints of every edge. No edge is added or deleted by relabeling.

Express the relabeling using an adjacency matrix

Let \(B_{ij}\) denote the adjacency-matrix entry for the relabeled graph. It equals 1 precisely when vertices \(i\) and \(j\) are adjacent in \(B\). To determine whether that edge exists, use \(\pi^{-1}\) to recover the two original vertices and check membership in \(E\):

\[B_{ij}=1\quad\Longleftrightarrow\quad \{\pi^{-1}(i),\pi^{-1}(j)\}\in E\]

For this undirected graph, the unordered pair \(\{a,b\}\in E\) means that \(a\) and \(b\) are adjacent. The inverse permutation restores the original vertex labels.

Why Hamiltonicity is preserved in both directions

Suppose \(v_1,\ldots,v_5,v_1\) is a Hamiltonian cycle in \(G\). Because \(\pi\) is a bijection, its five relabeled vertices are still distinct and cover all vertices. Because edges are preserved, every consecutive pair in \(\pi(v_1),\ldots,\pi(v_5),\pi(v_1)\) is an edge of \(B\). So \(B\) has a Hamiltonian cycle.

Conversely, if \(B\) has a Hamiltonian cycle, applying \(\pi^{-1}\) to every vertex preserves distinctness, coverage and edges, giving a Hamiltonian cycle in \(G\).

Thus \(G\) has a Hamiltonian cycle if and only if \(B=\pi(G)\) has one. Relabeling preserves the claim's truth while obscuring the original witness labels. \(\square\)

Why commit to \(B\) before the verifier chooses a challenge? The verifier will ask either whether \(B\) is an isomorphic copy of \(G\), or whether \(B\) contains a Hamiltonian cycle. The prover must be unable to change the committed graph between those alternatives.
