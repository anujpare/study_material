Part III · Graph Hamiltonicity

Why does the prover randomly permute the vertices?

In the Hamiltonicity proof, the prover knows a Hamiltonian cycle of the public graph \(G\). Revealing that cycle with its original vertex labels would reveal the witness. We therefore need to preserve the mathematical claim while concealing the correspondence between the proof's vertex labels and those of \(G\).

Relabeling a graph without changing its edges

Write \(G=(V,E)\), where \(V=\{1,2,3,4,5\}\) is the vertex set and \(E\) is the set of undirected edges. The lecture uses a permutation \(\Pi:V\to V\) to map each new vertex label back to its original label. Because \(\Pi\) is a bijection, the inverse \(\Pi^{-1}\) maps original labels to new labels.

Suppose the prover knows cycle \(1\to2\to3\to4\to5\to1\). The lecture's notation \(\Pi(i)\) means: if the relabeled graph uses vertex label \(i\), which vertex of the original graph does that label represent? Its inverse \(\Pi^{-1}(j)\) answers the opposite question: where did original vertex \(j\) move in the relabeled graph? These are addresses (vertex labels), not secret data values.

Initially, the lecture's mapping \(\Pi\) is: 1→3, 2→1, 3→5, 4→2, 5→4. The lab will show both directions in a table.

Construct a new graph \(B\) by assigning its edge \(\{i,j\}\) exactly when the original graph has edge \(\{\Pi(i),\Pi(j)\}\). Equivalently, each original edge \(\{u,v\}\) becomes \(\{\Pi^{-1}(u),\Pi^{-1}(v)\}\) in \(B\). This is a graph isomorphism. An edge remains an edge; only its endpoints' labels change.

Express the relabeling using an adjacency matrix

Let \(B_{ij}\) denote the adjacency-matrix entry for the relabeled graph. It equals 1 precisely when vertices \(i\) and \(j\) are adjacent in \(B\). To determine whether that edge exists, use \(\Pi\) to recover the two original vertices and check membership in \(E\):

\[B_{ij}=1\quad\Longleftrightarrow\quad \{\Pi(i),\Pi(j)\}\in E\]

For this undirected graph, the unordered pair \(\{a,b\}\in E\) means that \(a\) and \(b\) are adjacent. The permutation maps a vertex label in B back to the original graph.

Why Hamiltonicity is preserved in both directions

Suppose \(v_1,\ldots,v_5,v_1\) is a Hamiltonian cycle in \(G\). Because \(\Pi^{-1}\) is a bijection, its five relabeled vertices are still distinct and cover all vertices. Because edges are preserved, every consecutive pair in \(\Pi^{-1}(v_1),\ldots,\Pi^{-1}(v_5),\Pi^{-1}(v_1)\) is an edge of \(B\). So \(B\) has a Hamiltonian cycle.

Conversely, if \(B\) has a Hamiltonian cycle, applying \(\Pi\) to every vertex preserves distinctness, coverage and edges, giving a Hamiltonian cycle in \(G\).

Thus \(G\) has a Hamiltonian cycle if and only if \(B\) has one. Relabeling preserves the claim's truth while obscuring the original witness labels. \(\square\)

Why commit to \(B\) before the verifier chooses a challenge? The verifier will ask either whether \(B\) is an isomorphic copy of \(G\), or whether \(B\) contains a Hamiltonian cycle. The prover must be unable to change the committed graph between those alternatives.
