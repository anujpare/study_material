Part III · Graph Hamiltonicity

Randomly renaming a graph preserves its hidden cycle

The secret witness is a Hamiltonian cycle of a public graph \(G\). We want the prover to demonstrate knowledge of that cycle without displaying the original vertex order. A permutation lets us rearrange labels while keeping exactly the same connections.

Fix one graph and one permutation

Let \(G=(V,E)\), where \(V=\{1,2,3,4,5\}\) contains the vertices and \(E\) contains its edges. Suppose the prover knows the cycle \(1\rightarrow2\rightarrow3\rightarrow4\rightarrow5\rightarrow1\). A permutation \(\pi\) is a one-to-one renaming of the labels, so each old vertex obtains one unique new label.

\[\pi(1)=2,\quad\pi(2)=4,\quad\pi(3)=1,\quad\pi(4)=5,\quad\pi(5)=3\]

We use this one fixed example permutation throughout the following protocol cards. The real protocol chooses a fresh random permutation for each execution.

The full cycle becomes \(2\rightarrow4\rightarrow1\rightarrow5\rightarrow3\rightarrow2\).

Trace the mathematical invariant

Why does the cycle remain valid?

Reveal the exact relabeling. Follow one old edge, then the next, to see why all mapped edges still exist.

Each green edge in the second graph corresponds to exactly one green edge in the first. The gray chords are also relabeled, not erased.

Make the relationship exact

Let \(B_{ij}\) be the adjacency bit of the relabeled graph: it is 1 precisely when the old vertices corresponding to new labels \(i,j\) were connected. We use the inverse permutation \(\pi^{-1}\) to recover those old labels.

\[B_{ij}=1\quad\Longleftrightarrow\quad (\pi^{-1}(i),\pi^{-1}(j))\in E\]

A pair \((a,b)\in E\) means that an edge joins vertices \(a,b\) in \(G\). The inverse \(\pi^{-1}\) reverses the renaming; it is not another independently chosen permutation.

Why Hamiltonicity is preserved

Suppose \(v_1,\ldots,v_5,v_1\) is a Hamiltonian cycle of \(G\). Because \(\pi\) is one-to-one, \(\pi(v_1),\ldots,\pi(v_5)\) are five distinct vertices. Because every old cycle edge is mapped to a new graph edge, the relabeled sequence is also a cycle. Conversely, applying \(\pi^{-1}\) to any cycle of \(B\) gives a cycle of \(G\). Hence \(G\) has a Hamiltonian cycle if and only if \(B\) does.

The prover now commits to one such relabeled graph \(B\) and its permutation \(\pi\), before seeing the challenge. The verifier will ask for one of two incompatible kinds of evidence.
