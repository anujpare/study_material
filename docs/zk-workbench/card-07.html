Part III · Graph Hamiltonicity

What happens if we randomly rename every vertex?

Our prover knows a Hamiltonian cycle in a public graph \(G\), but it should not reveal which original vertices form that cycle in their original labels. We can change the vertex names without changing the roads. That simple observation is the next tool.

Fix one graph and one permutation

Write \(G=(V,E)\), where \(V=\{1,2,3,4,5\}\) lists the vertices and \(E\) lists the roads. Suppose the prover knows the cycle \(1\to2\to3\to4\to5\to1\). A permutation \(\pi\) gives every vertex a different new name. Because the renaming is one-to-one, it can also be undone.

\[\pi(1)=2,\quad\pi(2)=4,\quad\pi(3)=1,\quad\pi(4)=5,\quad\pi(5)=3\]

The screen uses one fixed renaming so that you can follow each road. The real prover chooses a fresh random permutation in each execution.

Follow the green roads. If the old road is \((1,2)\) and \(\pi(1)=2,\pi(2)=4\), its new name is \((2,4)\). Changing every label this way turns the original cycle into \(2\to4\to1\to5\to3\to2\). We haven't found a different cycle; we're looking at the same connections under new names.

Trace the mathematical invariant

Why does the cycle remain valid?

Reveal the exact relabeling. Follow one old edge, then the next, to see why all mapped edges still exist.

Each green edge in the second graph corresponds to exactly one green edge in the first. The gray chords are also relabeled, not erased.

Make the relationship exact

Call the relabeled graph \(B\). Its matrix entry \(B_{ij}\) is 1 when vertices with new names \(i,j\) are joined by a road. To determine whether that road existed originally, undo the renaming using \(\pi^{-1}\): the old vertices are \(\pi^{-1}(i)\) and \(\pi^{-1}(j)\).

\[B_{ij}=1\quad\Longleftrightarrow\quad (\pi^{-1}(i),\pi^{-1}(j))\in E\]

The notation \((a,b)\in E\) means there is a road between \(a\) and \(b\). The inverse permutation \(\pi^{-1}\) returns each new name to its original vertex; it is not a second random renaming.

Why Hamiltonicity is preserved

Here's why the cycle survives. Take any Hamiltonian cycle \(v_1,\ldots,v_5,v_1\) in \(G\). Since \(\pi\) is one-to-one, the five renamed vertices remain distinct. Each old road \((v_i,v_{i+1})\) becomes an actual road in \(B\). So the renamed sequence is a Hamiltonian cycle in \(B\). Conversely, applying \(\pi^{-1}\) to a cycle in \(B\) gives one in \(G\). Therefore one graph has a Hamiltonian cycle if and only if the other does.

Now the prover can commit to the relabeled graph before the verifier chooses a challenge. The verifier will test either whether the renaming is honest or whether the relabeled graph has a cycle.
