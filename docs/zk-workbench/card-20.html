Part VIII · Combining Sigma protocols

How do gate proofs establish circuit satisfiability?

Consider a Boolean circuit composed of gates, where each gate computes a prescribed Boolean operation on its input bits. We can prove that each gate's committed input and output values satisfy its relation. But does verifying all gate relations also establish that the complete circuit was evaluated correctly?

Begin with one gate, then connect the wires

The homework uses XOR and AND gates. XOR returns 1 when exactly one input is 1, so \(d=a\oplus b\). AND returns 1 when both are 1, so \(d=a\land b\). Here \(a,b\) are input bits and \(d\) is the output bit.

Understand the local statement

What must a gate-level proof establish?

Choose a gate and its two inputs. The prover should convince the verifier that the three hidden bits satisfy the right rule, using commitments and a gate-level Sigma proof.

The crucial detail is wiring. If gate 0's output feeds gate 1, the value at those two positions must be the same bit. Use one commitment for each logical wire and reuse it wherever that wire appears. Otherwise the prover could use different values at the two ends of the same wire.

Homework 2 · Problem 4(a)

Construct a Sigma protocol using \(N\) parallel gate proofs

Assume we already have perfectly binding, computationally hiding bit commitments and Sigma proofs for the XOR and AND relations. The question is how to combine one gate proof per gate into a proof for the entire circuit.

Protocol · commitment, challenge, response and verification

First message. Starting from a satisfying assignment, calculate every wire bit \(m_w\), choose fresh randomness \(r_w\), and commit once per wire: \(c_w=\mathrm{Commit}(m_w;r_w)\). For each gate \(j\), make the first message \(u_j\) of its XOR or AND Sigma proof using the commitments to its three wires. Send all commitments and \(u_j\) messages together.

Challenge. The verifier sends fresh independent challenges \(e_1,\ldots,e_N\), one for each of the \(N\) gate proofs.

Response. The prover sends all gate responses \(z_1,\ldots,z_N\) and opens the circuit's final output commitment to 1.

Verification. Check the output really opens to 1, and check every gate Sigma proof against those same wire commitments. Accept only when every test passes.

Homework 2 · Problem 4(b)

Prove soundness, not merely that gate checks exist

Why a false circuit must cause a false gate statement

Now prove soundness. Suppose the circuit \(C\) is unsatisfiable: no assignment makes its output 1. Perfect binding fixes one value for each committed wire, so the commitments give us one definite, though hidden, assignment to all wires.

If every gate relation were true for those fixed wire values, we could calculate the circuit gate by gate and obtain the committed final output. Since the verifier also demands an output of 1, those wire values would be a satisfying assignment. But we assumed no such assignment exists. Therefore at least one committed gate relation must be false.

So any accepted proof for an unsatisfiable circuit must include acceptance of at least one false gate statement. If the whole proof succeeds with probability \(\epsilon\) and there are \(N\) gates, some gate soundness failure must have probability at least \(\epsilon/N\). Otherwise the sum of all \(N\) failure probabilities could not reach \(\epsilon\).

If \(N\) is polynomially bounded and each gate proof has negligible soundness error \(\delta(\lambda)\), then the whole proof has error at most \(N\delta(\lambda)\), which is still negligible. If each gate proof only has constant error \(1/2\), we cannot claim this stronger conclusion without amplification.

Homework 2 · Problem 4(c)

The intended honest-verifier simulation—and its subtle assumption

Sketch the simulator; identify what a fully rigorous proof still needs

For zero knowledge, the homework proposes committing to convenient dummy wire bits, then simulating each gate transcript. Committing to 1 for every wire makes the final output commitment easy to open as 1.

There is a missing condition: an XOR gate with inputs 1 and 1 must output 0. Committing to 1 for all three wires makes that gate statement false. Ordinary honest-verifier zero knowledge only guarantees a simulator for true statements. It doesn't automatically simulate an accepting proof for that false dummy triple.

A rigorous simulation proof needs more than the assumptions as written: either a gate-proof simulator that can handle those false dummy statements or a carefully justified alternative simulation and hybrid argument. The homework gives the intended outline, not all the hypotheses needed for a formal proof.
