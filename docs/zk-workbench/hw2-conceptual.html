Homework 2 · Problem 1(a–c) · Conceptual questions

Who must behave honestly in a proof's security guarantee?

Completeness, soundness and zero knowledge are three different promises, with different parties required to behave honestly. The first exercise of Homework 2 checks whether we understand those quantifiers before studying repetition and the Hamiltonicity simulator.

HW2 Problem 1(a) · True or false?

If \(\mathrm P=\mathrm{NP}\), then zero-knowledge proofs exist for every NP language.

Solution

True. If \(\mathrm P=\mathrm{NP}\), membership in every NP language can be decided by a deterministic efficient algorithm. A verifier can simply run that algorithm without asking the prover for anything. That empty proof is perfectly complete and sound, and is zero knowledge because no secret witness or other information is transmitted. Here \(\mathrm P\) means efficiently decidable languages, while NP means efficiently verifiable YES certificates.

HW2 Problem 1(b.i) · True or false?

A malicious verifier interacting with an honest prover always accepts a true statement when the protocol has perfect completeness.

Solution

False. Completeness promises acceptance when both parties follow the prescribed protocol. A malicious verifier can ignore every message and output reject. Zero knowledge protects the honest prover's witness against such a verifier, but does not force the verifier to make an honest decision.

HW2 Problem 1(b.ii) · True or false?

An honest verifier interacting with a malicious prover must learn nothing except whether the statement is valid.

Solution

False. The zero-knowledge guarantee considers an honest prover interacting with any efficient verifier, including a malicious one. It does not constrain a malicious prover's choice to reveal secrets. A cheating prover could simply send the entire witness to an honest verifier, so the verifier's view would contain information beyond the statement's validity.

HW2 Problem 1(c) · True or false?

Non-interactive zero-knowledge proofs for languages in \(\mathrm P\) exist in the standard model without random oracles.

Solution

True. The verifier can decide membership by itself in polynomial time, and the prover sends an empty proof. Because there is no witness-dependent message, simulation is immediate. This does not imply that plain-model non-interactive ZK exists for every NP language; the later NIZK lesson explains why that stronger claim would have major complexity consequences.

These answers clarify the security experiments: completeness assumes both parties are honest; soundness allows a malicious prover but uses the prescribed verifier; zero knowledge allows a malicious verifier but uses the prescribed prover. We can now study how those guarantees behave when the interaction is repeated.
