What does it mean to prove a statement?

The lecture begins with a situation involving two parties: someone claims something is true, and someone else wants convincing evidence. Before introducing zero knowledge, we need to identify what is being claimed, what evidence is sent, and how the evidence is checked.

First identify the statement

A language \(L\) is a set of binary strings whose corresponding claims have a YES answer. A particular input \(x\) describes the statement we want to check. Writing \(x\in L\) means that statement is true; \(x\notin L\) means it is false.

As an example, consider the question “Does this graph have a Hamiltonian cycle?” A graph has vertices and edges connecting some pairs of vertices. A Hamiltonian cycle is a route along existing edges that visits each vertex once and returns to its starting vertex. Here \(x\) is the particular graph, and \(L\) is the set of all graphs for which the answer is YES.

Now identify who sends what

The prover \(P\) tries to establish the claim. The verifier \(V\) decides whether the evidence supports it. In a conventional one-shot proof, both know the public input \(x\), and the prover sends evidence \(\pi\) in one message. The verifier checks it and returns 1 for accept or 0 for reject.

Prover \(P(x)\)Finds evidence for the public claim \(x\)
Verifier \(V(x)\)Checks the evidence against the same \(x\)
Choose a proposed proof \(\pi\)
\(P\longrightarrow V:\ \pi\) Receive the proof
Run the checking algorithm; output 1 or 0

For our graph example, the proof can simply provide a proposed Hamiltonian cycle. The cycle is a witness \(w\): a piece of evidence whose validity can be checked without first having to discover it. The graph \(x\), the cycle \(w\), and the final accept/reject answer are three different objects.

The lecture's definition of NP

Let \(M(x,w)\) denote a deterministic checking algorithm. Its inputs are the public statement \(x\) and a proposed witness \(w\). It outputs 1 if the witness establishes the claim. A language belongs to NP if witnesses have length bounded by a polynomial in the length of \(x\), and \(M\) can check them in polynomial time.

\[x\in L\quad\Longleftrightarrow\quad\exists w\in\{0,1\}^{\operatorname{poly}(|x|)}:\ M(x,w)=1\]

Read the expression as: “\(x\) is a YES statement exactly when some short enough witness \(w\) makes the checker accept.” Here \(|x|\) is the number of bits used to describe \(x\), and \(\exists\) means “there exists.” A shorter witness can be padded to the stated bound.

The two directions are necessary. For a true statement, at least one witness must be accepted. For a false statement, no witness may be accepted. Rejecting one wrong guess does not establish that a statement is false.

Why checking can be easier than searching

For a graph of \(n\) vertices, one elementary way to search for a Hamiltonian cycle fixes the starting vertex and tries different orders of the remaining vertices: at most \((n-1)!\) candidates. The symbol \(!\) means factorial: for example, \(4!=4\cdot3\cdot2\cdot1=24\). Checking one proposed cycle takes \(n\) edge checks plus checking that it visits the vertices exactly once.
