Part I · What counts as a proof?

Why can finding a witness be harder than checking one?

We now know exactly how to verify a proposed Hamiltonian cycle: check that the vertex sequence includes every vertex once and that each consecutive pair is an edge. But what if nobody supplies a candidate sequence? We would have to find one ourselves.

Compare witness search with witness verification

Suppose \(G=(V,E)\) has \(n\) vertices. Fix vertex 1 as the start of the candidate cycle. There are \((n-1)!\) permutations of the remaining vertices, where \(!\) means factorial. For example, \(4!=4\cdot3\cdot2\cdot1=24\). Testing each permutation as a candidate gives a straightforward exhaustive search procedure.

This procedure may examine as many as \((n-1)!\) candidates. Some candidates are equivalent under reversing the cycle, but that doesn't matter for this simple upper bound. In contrast, once a candidate is provided, verification needs only \(n\) edge-membership checks, plus the checks that all \(n\) vertices occur exactly once. Those checks take polynomial time.

There is an important distinction: counting the candidates examined by this simple exhaustive method does not prove that every algorithm needs factorial time. The P versus NP question asks whether problems with efficiently verifiable witnesses always have efficient algorithms to find a solution or decide whether one exists.

The definition of NP

A language \(L\) is a set of inputs whose answer is YES. We write \(x\in L\) when the public statement \(x\) is true. A language is in NP when there is a polynomial-length witness \(w\) and a deterministic polynomial-time verifier \(M\) such that \(x\) is a YES instance if and only if some witness makes \(M\) accept:

\[x\in L\quad\Longleftrightarrow\quad\exists w:\ M(x,w)=1\]

The symbol \(\exists\) means “there exists”; \(\Longleftrightarrow\) means “if and only if.” Witness length and verification time are polynomially bounded in the input length.

The two directions matter. For every YES instance there must be some accepted witness. For every NO instance, no witness may be accepted. Merely rejecting one proposed witness isn't sufficient to establish a NO instance.

Why Hamiltonian Cycle belongs to NP

For a graph with \(n\) vertices, a witness consists of \(n\) vertex labels in the proposed cyclic order. The verifier checks that they are precisely the vertices of \(G\), with no repetitions, and that the \(n\) consecutive unordered pairs (including the last-to-first pair) belong to \(E\). These checks take polynomial time. Therefore the Hamiltonian-cycle decision problem is in NP.

Providing the full witness convinces the verifier but may reveal the witness itself. Our next task is to introduce a proof protocol whose verifier challenges the prover after the prover has fixed its first message. That order will be central to the soundness argument and, later, to zero knowledge.
