Part I · What counts as a proof?

Why checking can be easy while finding is hard

If someone gives us a route, checking every road is straightforward. But if nobody gives us a route, where do we start? We might try all the ways of ordering the cities, and there can be very many.

Compare the two tasks using the same graph problem

With \(n\) cities, fix city 1 as the start. There are \((n-1)!\) ways to order the others. The symbol \(!\) means factorial: \(4!=4\cdot3\cdot2\cdot1=24\). This gives us a simple search strategy, though not necessarily the best possible one.

A search that tests every order may need up to \((n-1)!\) candidate routes. Once a route is supplied, checking it needs only \(n\) road checks, counting the return to the first city. Those are very different amounts of work.

Don't confuse the number of candidates with a proof that every algorithm must try them all. We have only described one simple search. The unresolved P versus NP question asks whether problems with efficiently checkable witnesses can always be solved efficiently too.

Now state NP precisely

A language \(L\) is a set of YES inputs. We write \(x\in L\) when input \(x\) has the answer YES. The class NP consists of languages for which there is a short witness \(w\) and an efficient deterministic checker \(M\) with the property that \(x\) is a YES input exactly when at least one witness makes \(M(x,w)=1\).

\[x\in L \quad\Longleftrightarrow\quad \exists w:\ M(x,w)=1\]

The symbol \(\exists\) means “there exists”; \(\Longleftrightarrow\) means “if and only if”. The checker runs in polynomial time in the length of \(x\), and the witness has polynomial length.

The words “exactly when” are important. A YES input must have some accepted witness. A NO input must not have any accepted witness. Both directions are part of the definition.

Why this applies to Hamiltonian cycles

For Hamiltonian cycle, the witness is a list of \(n\) vertex labels. We check that every vertex appears once, that consecutive vertices are connected, and that the route returns to its start. These checks take polynomial time. So the Hamiltonian-cycle decision problem belongs to NP.

Ordinary NP proofs may simply reveal the witness. Next we'll give the verifier a way to ask a question that the prover cannot predict when preparing the proof.
