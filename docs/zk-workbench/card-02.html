What does it mean to prove a statement?

The lecture starts with a simple situation: someone claims something is true, and someone else wants to check the claim. To understand a proof, we need to identify the statement, the evidence, and the checking rule before introducing the mathematical definition.

1. What is the statement?

Consider the claim that a given number is the product of two prime numbers. A prime is an integer greater than 1 that has no positive divisors except 1 and itself.

Take the number 21. The claim is true because \(21=3\cdot7\), and both 3 and 7 are prime. The number 21 is the public input \(x\); the pair \((3,7)\) is evidence supporting it.

The lecture calls the set of all inputs with a YES answer a language \(L\). In this small illustration, \(L\) is the set of numbers that are products of two primes. Writing \(x\in L\) means that the claim about \(x\) is true. This is a set of inputs, not a spoken language.

2. Who sends what?

The prover \(P\) tries to convince the verifier \(V\). Both know the public number \(x=21\). The prover sends a proposed pair of factors; the verifier checks them.

Prover \(P(x)\)Finds candidate factors of 21
Verifier \(V(x)\)Knows 21, not necessarily the factors
Send candidate factors \((p,q)\)
\(P\longrightarrow V:\ (p,q)\) Receive the proposed factors
Check \(p\cdot q=21\) and whether both factors are prime; accept or reject

The proposed pair is a witness \(w\). A witness is information that lets the verifier check a statement efficiently. The public input \(x=21\), witness \(w=(3,7)\), and verifier output (accept/reject) are different objects.

3. Now the lecture's definition of NP

Write \(M(x,w)=1\) if a deterministic checking algorithm \(M\) accepts the proposed witness \(w\) for statement \(x\), and 0 otherwise. In our example, \(M(21,(3,7))=1\). The notation \(x\in L\) says the statement is true; \(M(x,w)=1\) says this particular witness passes the test.

The class NP consists of decision problems for which every YES input has a witness of polynomially bounded length that can be checked in polynomial time. “Polynomial time” means that the amount of work is bounded by some polynomial in the input's bit-length, rather than growing arbitrarily quickly.

\[x\in L\quad\Longleftrightarrow\quad \exists w\in\{0,1\}^{\operatorname{poly}(|x|)}:\ M(x,w)=1\]

Here \(|x|\) is the number of bits used to describe the input, \(\exists\) means “there exists”, and \(\operatorname{poly}(|x|)\) means a polynomial-length bound on the witness. Shorter witnesses can be padded. The displayed equivalence says that the statement is true if and only if some valid witness exists.

Why do we need both directions? If the claim is true, at least one witness must pass. If the claim is false, no witness may pass. A wrong guess for a true statement can fail, so rejecting one proposed witness never establishes the statement is false.

A standard one-shot proof sends the witness to the verifier. That can convince the verifier, but it also reveals the evidence. Later we will ask whether the verifier can be convinced without learning the witness.
